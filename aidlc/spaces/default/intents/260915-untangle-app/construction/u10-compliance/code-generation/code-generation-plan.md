# Plan de generación de código — U10 `compliance`

Lo que se construye: los tres controles del turno (guardia de salida, petición de
persona con la pregunta de identidad, emergencia), el registro de la
divulgación, la revisión completa de cuatro controles, el nodo `compliance` y la
delimitación del texto externo. Fuentes: `../functional-design/` (30 reglas),
`../nfr-requirements/` (NFR9 y NFR12 como compuertas duras), contratos C-04,
C-15 y C-20. Modo ligero (DP-12) y núcleo ahora (DP-14): lo que en vivo corre
contra el despliegue público queda para la pasada de publicación.

## Decisiones de este plan

| # | Decisión | Por qué |
