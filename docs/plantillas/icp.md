# Plantilla: Perfil de Cliente Ideal (ICP)

Plantilla estándar para documentar el Ideal Customer Profile de un producto o proyecto. Completa cada sección según tu contexto.

---

## Cómo usar esta plantilla

1. Copia este archivo y renómbralo (ej. `icp.md`, `icp-[nombre-proyecto].md`).
2. Sustituye los textos entre `[corchetes]` por la información de tu proyecto.
3. Ajusta el número de ítems en cada lista según necesites.
4. Elimina esta sección "Cómo usar" en la versión final si lo prefieres.

---

## Checklist antes de publicar

- [ ] Buyer Personas identificados y descritos en el párrafo inicial.
- [ ] Segmentos de cliente alineados con el producto/servicio.
- [ ] Dolores redactados desde la perspectiva del cliente (no del producto).
- [ ] Deseos vinculados a resultados o capacidades, no solo a funciones.
- [ ] Tono y lenguaje coherentes con el resto de la documentación del proyecto.
