Why this exists

Not another wrapper.

Calling a model is the easy part. Cautelia shows what most demos skip: what happens when the provider fails, where the state lives, where each figure comes from, and proof that it works.

  • Every citation verified
  • Insurers kept apart, tested
  • Data redacted before saving
  • An adjuster decides coverage

How it works

One orchestrator. Specialist agents. Small shared state.

Code, not the model, decides which node handles each turn. Nodes return structured results, never raw reasoning, so the context stays small and the trace reads top to bottom.

  1. Voice layer
  2. Orchestrator
  3. Specialist agents
  4. Tools
  5. Adjuster
  • 01

    Orchestrator

    Routes each turn in code and decides when an adjuster steps in.

  • 02

    Intake

    Gathers who, what, when and where while the caller talks, in any order.

  • 03

    Policy verification

    Cites only clauses that exist, belong to that policy and are in force. “Nothing found” and “could not check” are different answers.

  • 04

    Decision

    Applies the insurer’s versioned, tested rules. The model never picks the category.

  • 05

    Compliance

    Reviews the case before it closes.

Voice

Fast enough to feel like a call. Patient enough not to interrupt.

  5. Streaming text to speechstreams
  • The hard part is knowing when someone has finished. Cautelia waits for meaning, not silence: whoever dictates a plate pauses mid-number.
  • The caller can interrupt. The agent stops mid-sentence, keeps the state, and picks up where the caller left it.
  • The heavy work (policy checks, rules, compliance) never runs inside the turn, so answer time does not depend on how many rules an insurer has.

Guardrails

The agents gather. Adjusters decide.

A report is intake and coordination, not judgment. Cautelia never says something is covered, never denies it and never mentions amounts: it hands the case to an adjuster with the trace attached.

  • Before the model: outside text enters as data, never inside the prompt.
  • In flight: every tool call is validated against its schema.
  • Before anything leaves: every message, errors included, passes one exit guard.
  • Above all: if someone reports a serious injury, the agent stops collecting data and gives the emergency phrase.

Evals

Every change is tested. What fails is shown.

Scripted conversations with known answers run on every change. Pass or fail per case, Spanish and English apart, never averaged. A failing case stays visible: it is never removed to make a number go up.

Every call leaves a nested trace, so a claim can be followed from the first word to the closed record.
